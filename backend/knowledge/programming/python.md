# Python and Programming Languages

Source: Python documentation and the Python project history maintained by the Python Software Foundation.

## What Is a Programming Language?

A programming language is a formal way to write instructions that a computer can execute. Languages provide rules for expressing values, decisions, repetition, and reusable operations. A compiler or interpreter translates those instructions into operations the computer can perform.

## Python

Python is a high-level, general-purpose programming language. Its readable syntax, dynamic typing, standard library, and broad package ecosystem make it useful for scripting, automation, web services, data analysis, and machine learning. Python programs are commonly stored in `.py` files and executed by a Python implementation such as CPython.

## History of Python

Guido van Rossum began developing Python in the late 1980s at Centrum Wiskunde & Informatica in the Netherlands. Python was designed partly as a successor to the ABC language, and its first public release was in 1991. Readability and practical programming were central goals of the language's design.
