## Non-authoritative and test inputs

- `masterdb/balbharti/sample_dataset.json`, `sample_ingestion_dataset.json`, `testing_dataset.json`, and `experimental_dataset.json` are separate from the canonical dataset path used by `retrieval/retrieval_engine.py`. Do not merge them into canonical retrieval without an explicit ingestion/authority decision.
- Unit-test fixtures and synthetic candidates in `backend/tests/` are not production knowledge. Existing convergence tests use source labels such as `MASTERDB`, `AKASHIC`, and `FAISS_VECTOR_INDEX` to exercise policy behavior; those examples are not evidence of external integration.
- The ZIP contains an embedded `bhiv-uniguru-main/` subtree. It was left untouched and is not assumed to be another live runtime source.
